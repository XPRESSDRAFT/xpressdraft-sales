## 2. Add these on Render (Environment)

| Key | Where to get it |
|---|---|
| `CLOCKIFY_API_KEY` | Clockify → Profile settings → API → Generate |
| `CLOCKIFY_WORKSPACE_ID` | Clockify → Workspace settings; the ID is in the page address |
| `CLOCKIFY_WEBHOOK_SECRETS` | From step 3: each webhook's signing token, separated by commas |
| `ALERT_EMAIL` *(optional)* | Where problem emails go. Default: info@xpressdraft.com.au |
| `CLOCKIFY_API_BASE` *(only if needed)* | Only if your Clockify workspace is on a regional server (e.g. Australia). Otherwise leave it out |

`ANTHROPIC_API_KEY` and `MONDAY_API_KEY` are already set.

## 3. Create the Clockify webhooks

In Clockify, open **Settings → Webhooks** (you need to be a workspace admin) and add:

| Event | URL |
|---|---|
| New time entry | `https://xpressdraft-sales.onrender.com/api/clockify-webhook` |
| Time entry updated | `https://xpressdraft-sales.onrender.com/api/clockify-webhook` |
| Timer stopped *(if offered)* | `https://xpressdraft-sales.onrender.com/api/clockify-webhook` |
| Time entry deleted | `https://xpressdraft-sales.onrender.com/api/clockify-webhook?event=deleted` |

Copy each webhook's **signing token/secret** into `CLOCKIFY_WEBHOOK_SECRETS` on Render, comma-separated.
